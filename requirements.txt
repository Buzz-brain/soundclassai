# Runtime dependencies for the Environmental Sound Classification System.
#
# Install with:  pip install -r requirements.txt
# (A virtual environment is strongly recommended.)
#
# Versions are pinned to match the local .venv (Python 3.11.9), so the
# production build on Render resolves the exact same wheels.
#
# NOTE: TensorFlow/Keras are intentionally ABSENT. The server serves the
# model through ONNX Runtime (best_model.onnx), which keeps the process
# around 150 MB instead of ~450 MB — the difference between fitting and
# OOM-killing on Render's free 512 MB tier. The ONNX file is produced
# locally with tools/convert_to_onnx.py (which needs tensorflow + onnx +
# tf2onnx as dev-only dependencies).
